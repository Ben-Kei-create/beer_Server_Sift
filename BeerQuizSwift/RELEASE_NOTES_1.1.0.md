# ビール雑学クイズ 1.1.0 リリースノート

## App Store「このバージョンの最新情報」案

- 結果画面からスコアをシェアできるようになりました
- 正解・不正解・終了時に効果音が鳴ります（設定でON/OFF可能）
- 設定画面を追加しました（効果音・触覚フィードバック・成績リセット）
- ハイスコアと累計正答率をホーム画面に表示します
- 間違えた問題だけを出題する「復習モード」を追加しました
- 毎日1問だけ出題される「今日の1問」を追加しました

## 技術メモ
- MARKETING_VERSION 1.1.0 / CURRENT_PROJECT_VERSION 2
- 成績データは端末内（UserDefaults）にのみ保存。外部送信なし（プライバシーポリシー変更なし）
